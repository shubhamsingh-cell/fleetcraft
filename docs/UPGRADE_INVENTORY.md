# Upgrade inventory — September 7, 2026

This is a public distribution decision record, not an installer or a claim to include
an entire personal agent environment. Source review covered the earlier Fleetcraft
candidate and the subsequent local capability handoff. Only portable, relevant
instructions belong in this repository.

## Bundled

- **Plugin hardening:** self-contained package, doctor, malformed-input fixtures,
  opt-in strict hook decisions, isolated installation, pinned CI and tag validation.
- **Execution contracts:** bounded delegation, explicit ownership, independent review,
  reproduction before fixes, pre-fix regression evidence, honest unresolved checks.
- **Design refinement:** approved baseline and product truth govern changes; verify
  rendered states and accessibility instead of accepting source edits as visual proof.
- **Change planning:** known/assumed/unknown facts, scope, acceptance and abort checks,
  rollback or forward recovery. A plan does not authorize implementation.
- **Image-to-code:** separate visible evidence from inferred responsive behavior,
  interactions and motion; compare at the same viewport.
- **Project handoff:** durable decisions, artifacts, ownership, actual validation and
  unresolved gates, with sensitive operational context omitted.

These are instructions and local runtime checks. They establish neither benchmark
superiority nor general reliability across models and operating systems.

## Optional integrations, not bundled

| Capability | Adoption boundary |
|---|---|
| Browser automation and visual comparison | Detect an available tool; obtain approval for a pinned installation if absent. |
| Secret, dependency, workflow and configuration scanners | Scope each scan and report its coverage; a clean scan is not a security guarantee. |
| Repository graphs and context bundles | Check freshness, repository scope and exclusions before trusting or sharing output. |
| Debugging and performance specialist packs | Evaluate overlap, license, version and measured behavior before adopting a separate pack. |
| Model/provider routers, remote MCP servers and lifecycle hooks | Review credentials, side effects, telemetry and rollback separately; do not auto-install. |
| Host-provided document, spreadsheet and connector capabilities | Use the receiving host's authorized tools; do not redistribute proprietary bundles. |

The reviewed resource catalog contained references and deferred experiments as well as
usable capabilities. Inclusion in that catalog never established compatibility,
redistribution rights, or permission to configure a service. Private inventories,
conversation logs, credentials and machine-specific configuration are excluded.
