# Image to Code

Treat the supplied screenshot or mockup as the source of truth. Record observed layout, type,
spacing, palette, controls, and authorized assets. Mark unseen behavior, responsive behavior,
and missing assets as inferred.

Reuse existing components and authorized assets. Preserve semantic structure, keyboard access,
focus visibility, contrast, and reflow. Render at the reference viewport, compare structure,
spacing, type, then details, and report unresolved differences. A still image does not establish
motion; request an explicit decision before adding it.
